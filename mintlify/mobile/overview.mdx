## Source

This is a git submodule at `auxi/`. The authoritative conventions live in
`auxi/CLAUDE.md` — RN-specific rules, navigation registration, dual-Home
migration status. When that conflicts with anything here, the per-repo
file wins.

## Working in the mobile repo

- All code changes go through the `mobile-dev` agent.
- Figma work requires both `figma-design-extraction` and `figma-to-rn-workflow`
  skills.
- Visual fidelity is enforced by `qa-ui` (compare mode), execution by `qa-mobile`.

See [Figma workflow](/mobile/figma-workflow) and [QA & testing](/mobile/qa-and-testing).
