# Phase 1 Plan: Remix Backend

## Goal

Land a production-ready `POST /api/v05/recommendation/next` endpoint, backed by a Redis-stored session that cycles through 4 variation axes (SILHOUETTE → LAYERING → COLOR → NEW_ANCHOR), enforces anchor-pin and single-layer-swap invariants as hard-fails, and meets p95 < 250ms under 1-user load. PR open by EOD 2026-05-09 and mergeable by 2026-05-10 (Cycle 10 close).

## Out of Scope

Explicit guardrails to keep the plan small enough to ship in 2 days:

- **Mobile wiring** — Phase 3
- **Telemetry events** (Mixpanel emission) — backend only adds `trace.variation_axis` to response; mobile fires the events
- **V05 onboarding API** (ONBD-01..03) — Phase 4
- **CORS / JWT secret hardening** — Phase 2 (FOUND-04)
- **Maestro E2E** — Phase 5 (LAUNCH-01)
- **Concurrent / multi-user load testing** — single-user p95 only per REMIX-BE-08
- **LLM narration on NEW_ANCHOR** — explicit Phase 2 stretch in PRD
- **Color-pair learning** (V05 spec §15.7) — Phase 3+
